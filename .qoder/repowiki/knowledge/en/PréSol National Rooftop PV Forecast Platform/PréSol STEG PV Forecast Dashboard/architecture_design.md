The module is a static HTML/JS dashboard served as flat pages under `dashboard/`, each page (`index.html`, `districts.html`, `map.html`, `performance.html`, `alerts.html`, `registry.html`, `prosol-history.html`) declaring a `data-page` attribute on `<body>` that drives a simple client-side router in `assets/js/core.js`. A single entrypoint `assets/js/app.js` dynamically injects shared and per-page script modules via `document.write`, loading `core.js` plus one feature module per page. `core.js` centralizes cross-cutting concerns: design tokens (`C`), Chart.js defaults, i18n (English/French/Arabic via i18next with `data-i18n` attributes), global status polling (`/status`, `/cache/status`, `/alerts`), and the Prosol Report Studio modal. Each feature module exposes an `initXxx()` function (e.g. `initHome`, `initDistricts`, `initTimelapseMap`, `initPerformance`, `initAlerts`, `initRegistry`, `initProsolHistory`) registered by the router. All server communication goes through a single `API_BASE = 'http://localhost:8000'` constant using `fetch`, targeting endpoints such as `/steg-districts`, `/forecast/timelapse`, `/forecast/map`, `/reports/prosol/summary`, and `/registry/pipeline`. The map page uses Leaflet with OpenStreetMap and Esri Light Canvas basemaps; charts use Chart.js with zoom/annotation plugins loaded from CDN. Static assets (CSS, GeoJSON outlines, demo data, intro video) live under `assets/`.
