Two sibling packages collaborate through shared file-system contracts rather than direct imports: `reports/` (prosol_reports) builds normalized Prosol snapshots from STEG's dashboard text, persists them in SQLite via `prosol_history_db.py`, layers append-only live installation deltas via `prosol_updates.py`, and renders an official print-ready HTML report in `prosol_report_generator.py`; `evaluation_metrics` runs forecast-vs-measurement comparisons and writes immutable `summary.json` plus `historical_metadata.json` files under `results/forecast_evaluations/` or `evaluations/`. The cross-child bridge is the `evaluation_registry.py` module, which scans those same filesystem roots to discover evaluation summaries for the API/dashboard, while `prosol_report_generator.py` consumes both the Prosol snapshot pipeline (`generated/prosol_*.json`) and the live-updates layer (`aggregate_updates()`) to produce the final report. A single top-level `report/generate_report.py` entrypoint ties the two pipelines together for end-to-end execution.
