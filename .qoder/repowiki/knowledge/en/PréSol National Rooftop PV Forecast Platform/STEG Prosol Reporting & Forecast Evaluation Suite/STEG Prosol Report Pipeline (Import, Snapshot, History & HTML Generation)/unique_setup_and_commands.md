Report ingestion expects a PDF converted via `pdftotext -layout report.pdf report.txt`; the CLI entry point is `python -m reports.prosol_report_importer <source.txt> --output reports/generated/<name>.json [--csv-dir ...] [--registry ...]`. Live updates are appended to `results/prosol_updates/installation_updates.jsonl` via `add_installation_update`, and historical snapshots are bulk-loaded with `import_generated_snapshots` from `reports/generated/prosol_*.json` into `results/prosol_history.db`.
