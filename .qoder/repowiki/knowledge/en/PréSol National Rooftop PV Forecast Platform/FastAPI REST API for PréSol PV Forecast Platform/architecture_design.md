The module is organized as a standard FastAPI application: `main.py` constructs the `FastAPI` app, registers CORS middleware, wires a lifespan context manager, and includes all domain routers. `core.py` holds global process state (`_state` dict with models, cache, refresh lock), path constants, an API-key security scheme via `APIKeyHeader`, lazy model loading, a cached `build_forecast` pipeline that falls back from live weather to synthetic data, bias correction over metering buffer, and two background jobs (forecast refresh every 15 min, daily retrain) driven by APScheduler's `BackgroundScheduler`. The `routers/` subpackage splits endpoints by domain — `forecast.py` (national/direction/district/governorate map/timelapse/export), `meta.py` (service root, status, registry of districts and governorates), `diagnostics.py` (alerts, metrics, history), `learning.py` (model training/retrain triggers), and `reports.py` (ProSOL report generation). Routers depend on `api.core` for shared state and on sibling packages (`data.steg_districts`, `models.*`, `ingestion.*`, `reports.*`) but are never imported by `core`, keeping dependency direction one-way into business logic.
