Flat results workspace organized by artifact type rather than code modules. `datasets/` holds input/derived CSVs (rooftop training, history, sample) and a per-district `pvgis_cache/` of JSON weather caches used to generate national forecasts. `forecast_evaluations/<run_id>/` groups actual/forecast/evaluated series with per-run `historical_metadata.json` and `summary.json`. `model_registry/` is a simple file-based ML registry: `model_versions.json` lists all trained models with status (`archived`/`production`), feature/schema versions, and metrics; `training_runs.json` records each run's lifecycle; `production_model.json` is the promotion pointer; `artifacts/` stores serialized `.joblib` model files. Top-level CSVs (`history_national.csv`, `metrics_by_horizon.csv`, `retrain_log.csv`) aggregate national forecast outputs and retraining history, while SQLite databases (`presol.db`, `prosol_history.db`) store operational state. `prosol_updates/installation_updates.jsonl` is an append-only event log of manual capacity updates from the frontend. `figures/` and `steg_prosol_mars_2026.html` are static visualization outputs consumed by dashboards.
