Run dataset generation as Python modules: `python -m data.generate_rooftop_dataset --start YYYY-MM-DD --end YYYY-MM-DD --output results/datasets/rooftop_training.csv [--district ...] [--frequency h|15min]`; PVGIS variant uses `python -m data.generate_pvgis_rooftop_data --start --end --cache-dir results/datasets/pvgis_cache`. Both require internet access for the PVGIS path; the synthetic path works fully offline. Each generator writes a versioned `dataset_version` string into the output rows.
